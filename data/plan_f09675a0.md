# Test Plan: Zhihui Workshop (智慧工坊)

## Overview
**Project Name**: Zhihui Workshop
**Framework**: React
**Testing Tool**: Playwright

This application appears to be a comprehensive image processing and design platform, likely offering services such as ID photo creation, poster design, general photo editing, and order management. The test plan is derived from the existing test directory structure (`tests/home`, `tests/idphoto`, `tests/poster`, etc.) and standard React application behaviors.

The plan focuses on end-to-end (E2E) testing scenarios to ensure critical user flows function correctly across different modules.

---

## Suite: Home Module (tests/home)
Focuses on the landing page, navigation, and initial user interaction.

### TC-HOME-001: Verify Homepage Load and Layout
- **Steps**:
  1. Navigate to the application root URL.
  2. Wait for the page load state to be 'networkidle'.
  3. Check for the presence of the main header, navigation bar, and footer.
- **Expect**: The homepage renders correctly without console errors. Key UI elements (Logo, Menu, Banner) are visible.

### TC-HOME-002: Navigation to Feature Modules
- **Steps**:
  1. On the Homepage, locate the navigation menu.
  2. Click on the "ID Photo" (证件照) link/button.
  3. Verify URL changes to the ID Photo module path.
  4. Navigate back and click "Poster" (海报).
  5. Verify URL changes to the Poster module path.
- **Expect**: Navigation correctly routes the user to the respective modules without page reload errors.

---

## Suite: ID Photo Module (tests/idphoto)
Focuses on the ID photo creation workflow, including upload, processing, and download.

### TC-IDP-001: Upload Photo for ID Processing
- **Steps**:
  1. Navigate to the ID Photo module.
  2. Click the "Upload" button or drag-and-drop area.
  3. Select a valid JPG/PNG image file from the local system using `page.setInputFiles`.
  4. Wait for the upload success indicator or preview image to appear.
- **Expect**: The image uploads successfully, and a preview of the uploaded photo is displayed to the user.

### TC-IDP-002: Change Background Color
- **Steps**:
  1. Assuming a photo is uploaded (Pre-condition).
  2. Locate the background color options (e.g., Blue, Red, White).
  3. Click on the "Blue" color option.
  4. Observe the preview area.
- **Expect**: The background of the ID photo in the preview updates to the selected color immediately.

### TC-IDP-003: Download Processed ID Photo
- **Steps**:
  1. Process a photo with a specific background color.
  2. Click the "Download" or "Save" button.
  3. Wait for the download event.
- **Expect**: The processed image file downloads successfully to the local filesystem.

---

## Suite: Poster Module (tests/poster)
Focuses on the poster design editor functionality.

### TC-PST-001: Select Poster Template
- **Steps**:
  1. Navigate to the Poster module.
  2. Browse the template gallery.
  3. Click on a specific template thumbnail.
- **Expect**: The editor loads with the selected template, displaying the canvas and editing tools.

### TC-PST-002: Edit Text on Poster
- **Steps**:
  1. Load a poster template.
  2. Click on a text element on the canvas.
  3. Clear existing text and type "Test Event Title".
  4. Click outside the text box to deselect.
- **Expect**: The text on the canvas updates to "Test Event Title" and renders correctly.

---

## Suite: Photo Module (tests/photo)
Focuses on general photo editing features (beautification, cropping, filters).

### TC-PHT-001: Apply Image Filter
- **Steps**:
  1. Navigate to the Photo module.
  2. Upload a sample photo.
  3. Select a filter option (e.g., "Grayscale" or "Vintage") from the toolbar.
  4. Verify the canvas updates.
- **Expect**: The photo preview reflects the applied filter style.

### TC-PHT-002: Crop Image Functionality
- **Steps**:
  1. Upload a photo.
  2. Select the "Crop" tool.
  3. Adjust the crop bounding box to a smaller area.
  4. Click "Apply" or "Confirm".
- **Expect**: The image is cropped to the selected area, and the preview updates accordingly.

---

## Suite: Orders Module (tests/orders)
Focuses on the user's order history and payment status.

### TC-ORD-001: View Order History
- **Steps**:
  1. Log in as a registered user (handle authentication state).
  2. Navigate to the "My Orders" or "Order History" page.
  3. Verify the list of orders is loaded.
- **Expect**: A list of past orders is displayed, showing order ID, date, and status.

### TC-ORD-002: Filter Orders by Status
- **Steps**:
  1. On the Orders page, locate the status filter dropdown/tabs.
  2. Select "Completed" (已完成).
  3. Check the order list.
- **Expect**: The list updates to show only orders with "Completed" status.

---

## Suite: Hall Module (tests/hall)
Focuses on the "Hall" or public gallery/workspace features.

### TC-HALL-001: Browse Public Gallery
- **Steps**:
  1. Navigate to the Hall module.
  2. Scroll down to verify lazy loading or pagination of content items.
- **Expect**: Content items (images/projects) are displayed in a grid layout. Scrolling loads more items if available.

### TC-HALL-002: Search Functionality
- **Steps**:
  1. Locate the search bar in the Hall module.
  2. Enter a keyword (e.g., "Summer").
  3. Press Enter or click the Search icon.
- **Expect**: The results display items related to the keyword "Summer".

## Suite: Generated Content Module (tests/generated)
Focuses on AI-generated or system-generated content management.

### TC-GEN-001: View Generated History
- **Steps**:
  1. Navigate to the Generated content section.
  2. Verify the existence of a list or grid of previously generated items.
- **Expect**: The user can see a history of AI-generated images or content with thumbnails and timestamps.

### TC-GEN-002: Regenerate or Delete Item
- **Steps**:
  1. Hover over a generated item.
  2. Click the "Delete" or "Regenerate" button.
  3. Confirm the action in the modal.
- **Expect**: The item is removed from the list or updated based on the action taken.
