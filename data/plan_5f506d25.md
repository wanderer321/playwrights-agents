## Suite: 01_User_Login_And_Authorization
*Focus: WeChat specific user identity and permissions.*

### TC-AUTH-001: WeChat Silent Login
- **Steps**:
  1. Launch the Mini Program.
  2. Check the current page path and user status.
- **Expect**: 
  - App launches successfully.
  - If `openid` exists, user is logged in automatically without popups.
  - Home page loads user-specific data (e.g., "My Activities" count).

### TC-AUTH-002: User Profile Authorization (Avatar/Nickname)
- **Steps**:
  1. Navigate to User Profile page.
  2. Click "Edit Profile" or trigger the authorization button.
  3. Mock the `wx.getUserProfile` or `button open-type="chooseAvatar"` interaction.
- **Expect**: 
  - Authorization popup appears (or avatar selection interface).
  - After confirmation, the user's avatar and nickname update on the profile page.

### TC-AUTH-003: Location Permission
- **Steps**:
  1. Enter the "Activity List" or "Nearby Activities" page.
  2. Trigger location retrieval (`wx.getLocation`).
- **Expect**: 
  - System prompts for location permission.
