# Test Plan: Zhihui Workshop (智慧车间)

## Overview
**Project Name**: Zhihui Workshop (智慧车间)
**Framework**: React
**Test Tool**: Playwright
**Description**: This application appears to be a smart workshop or studio management platform, likely involving photo processing services. Based on the directory structure, the application includes modules for a general hall/exhibition, home dashboard, ID photo processing, general photo services, poster creation, and order management.

**Test Strategy**: The test plan focuses on end-to-end (E2E) testing of user flows across the identified modules. Tests will verify UI rendering, user interactions, and functional correctness of the React components.

---

## Suite: Home Module (首页模块)
**Location**: `tests/home`

### TC-HOME-001: Verify Home Page Load and Layout
- **Steps**:
  1. Navigate to the root URL of the application.
  2. Wait for the page load state to be 'networkidle'.
- **Expect**: The home page renders successfully with the main navigation bar, footer, and primary content area visible. No console errors are present.

### TC-HOME-002: Verify Navigation Menu Responsiveness
- **Steps**:
  1. On the Home page, check the visibility of the navigation links (e.g., Hall, ID Photo, Poster, Orders).
  2. Resize the browser viewport to mobile dimensions.
- **Expect**: Navigation links are visible on desktop. On mobile, a hamburger menu or responsive navigation pattern appears.

---

## Suite: Hall Module (大厅/展厅模块)
**Location**: `tests/hall`

### TC-HALL-001: Display Service List
- **Steps**:
  1. Navigate to the Hall/Exhibition page.
  2. Verify the presence of service cards or list items.
- **Expect**: A list of available services (e.g., ID Photo, Photo Print, Poster Design) is displayed correctly with thumbnails and titles.

### TC-HALL-002: Service Search Functionality
- **Steps**:
  1. Locate the search input field on the Hall page.
  2. Input a valid service name (e.g., "证件照").
  3. Press Enter or click the Search button.
- **Expect**: The list updates to show only matching results. The target service appears in the results.

## Suite: ID Photo Module (证件照模块)
**Location**: `tests/idphoto`

### TC-IDPHOTO-001: Upload Photo for ID Processing
- **Steps**:
  1. Navigate to the ID Photo module.
  2. Click the "Upload" button.
  3. Select a valid image file (JPG/PNG) from the local filesystem.
- **Expect**: The image uploads successfully and a preview is displayed in the editing interface.

### TC-IDPHOTO-002: Change Background Color
- **Steps**:
  1. Assuming a photo is uploaded, locate the background color options (e.g., Blue, White, Red).
  2. Select "Blue".
- **Expect**: The background of the preview image changes to Blue immediately.

### TC-IDPHOTO-003: Select Photo Specifications
- **Steps**:
  1. Locate the specification selector (e.g., One-inch, Two-inch, Passport).
  2. Select "One-inch" (一寸).
- **Expect**: The cropping box or preview adjusts to the aspect ratio of a One-inch photo.

## Suite: Photo Module (照片处理模块)
**Location**: `tests/photo`

### TC-PHOTO-001: Basic Photo Editing Tools
- **Steps**:
  1. Navigate to the general Photo module.

## Suite: Orders Module (订单模块)
**Location**: `tests/orders`

### TC-ORDERS-001: View Order History
- **Steps**:
  1. Navigate to the Orders page.
  2. Verify the list of past orders.
- **Expect**: A list of orders is displayed, showing Order ID, Date, Status, and Amount.

### TC-ORDERS-002: Filter Orders by Status
- **Steps**:
  1. Locate the status filter tabs (e.g., All, Pending, Completed, Cancelled).
  2. Click on the "Completed" tab.
- **Expect**: The list refreshes to show only orders with "Completed" status.

### TC-ORDERS-003: View Order Detail
- **Steps**:
  1. Click on a specific order item from the list.
- **Expect**: A detail view or modal opens showing specific items, payment info, and delivery status.
