# Test Plan: pure-activity

## Overview
- **Project Name**: pure-activity (原生小程序)
- **Scale**: Large (81 Pages, 5 Components)
- **Framework**: WeChat Native
- **Description**: A large-scale activity management platform. Given the name and scale, the application likely supports activity publishing, browsing, registration/booking, payment, and user interaction. The test strategy focuses on the core user journey from discovery to participation, ensuring WeChat ecosystem features (Login, Payment, Share) function correctly.

## Suite: 01_User_Authentication
### TC-AUTH-001: WeChat User Login
- **Steps**:
  1. Launch the Mini Program.
  2. Check if the user is currently logged in.
  3. If not logged in, trigger the login flow (e.g., clicking "Me" tab or a specific "Login" button).
  4. Verify the WeChat authorization popup appears.
  5. Click "Allow" to authorize user info.
- **Expect**: User profile (Avatar, Nickname) is displayed correctly on the user page; Global login state is maintained.

### TC-AUTH-002: Get User Phone Number
- **Steps**:
  1. Navigate to the User Center or Order Creation page.
  2. Click a button requiring phone number binding (e.g., "Bind Phone" or "Pay").
  3. Verify the WeChat phone number authorization popup appears.
  4. Click "Allow".
- **Expect**: Phone number is successfully retrieved and bound to the user account; No error toast appears.

## Suite: 02_Home_And_Discovery
### TC-HOME-001: Home Page Load and Navigation
- **Steps**:
  1. Launch the Mini Program to load the Home page.
  2. Verify that the activity list or banner images load successfully.
  3. Scroll down to trigger lazy loading (if applicable).
  4. Click on a banner or activity card.
- **Expect**: Home page renders without layout issues; Navigation to the Activity Detail page occurs correctly.

### TC-HOME-002: Activity Search and Filter
- **Steps**:
  1. Navigate to the search page or use the search bar on the home page.
  2. Input a keyword (e.g., "Hiking").
  3. Click Search.
  4. Apply filters (e.g., Date, Location, Category).
- **Expect**: Search results match the keyword; Filters correctly narrow down the activity list.

## Suite: 03_Activity_Detail_And_Interaction
### TC-DETAIL-001: View Activity Details
- **Steps**:
  1. Navigate to a specific Activity Detail page.
  2. Verify key elements: Title, Time, Location, Price, Description, Organizer Info.
  3. Scroll to the bottom.
- **Expect**: All data is displayed correctly; No broken images or missing text.

### TC-DETAIL-002: WeChat Location Navigation
- **Steps**:
  1. On the Activity Detail page, locate the "Location" or "Map" icon.
  2. Click the location element.
  3. Verify `wx.openLocation` is triggered.
- **Expect**: The WeChat map interface opens centered on the activity location; Navigation controls are available.

### TC-DETAIL-003: Share Activity
- **Steps**:
  1. On the Activity Detail page, click the top-right menu "..." or a dedicated "Share" button.
  2. Select "Forward to Friends" or "Share to Timeline".
- **Expect**: The share card displays the correct Activity Title and Image; Recipient can click the card to open the specific activity page.

## Suite: 04_Booking_And_Payment
### TC-PAY-001: Create Order and WeChat Pay
- **Steps**:
  1. On the Activity Detail page, click "Sign Up" or "Buy Ticket".
  2. Fill in required registration fields (Name, ID, etc.).
  3. Click "Submit Order".
  4. Verify the order summary page.
  5. Click "Pay" to trigger `wx.requestPayment`.
  6. Complete payment in the WeChat payment interface (use sandbox/test account).
- **Expect**: Payment interface pops up; After successful payment, the page redirects to "Payment Success" or "Order Details"; Order status updates to "Paid".

### TC-PAY-002: Payment Cancellation
- **Steps**:
  1. Repeat steps 1-5 from TC-PAY-001.
  2. Click "Cancel" on the WeChat payment interface.
- **Expect**: Payment interface closes; Order status remains "Unpaid" or "Pending"; User is prompted to continue payment or cancel order.

## Suite: 05_User_Center
### TC-USER-001: View My Orders
- **Steps**:
  1. Navigate to the User Center ("Me" tab).
  2. Click "My Orders".
  3. Verify tabs for different statuses (All, Pending, Paid, Completed, Cancelled).
  4. Click on a specific order.
- **Expect**: Order list loads correctly; Clicking an order navigates to the specific Order Detail page with correct information.

### TC-USER-002: Cancel Order
- **Steps**:
  1. Navigate to an "Unpaid" or "Pending" order.
  2. Click "Cancel Order".
  3. Confirm the cancellation in the modal.
- **Expect**: Order status changes to "Cancelled"; If applicable, inventory/seat is released.

## Suite: 06_Component_Testing
### TC-COMP-001: Custom Tab Bar Navigation
- **Steps**:
  1. Inspect the custom tab bar component (if used, common in native apps with 5 components).
  2. Click each tab item (Home, Category, Me, etc.).
- **Expect**: Page switches correctly; Active tab icon/text style changes accordingly.

### TC-COMP-002: Activity Card Component
- **Steps**:
  1. Identify a page listing multiple activities (e.g., Home, Search results).
  2. Verify the Activity Card component renders consistently across different data sets (Long titles, missing images, varying prices).
- **Expect**: Layout does not break; Text truncation works; Default images appear if original fails to load.
