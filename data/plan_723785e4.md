根据项目信息分析，该项目名为 "pure-activity"（纯净活动/纯活动），是一个拥有95个页面的大型原生微信小程序。项目规模较大，推测为活动发布、报名、管理类应用。

以下是基于 Minium 框架的测试计划：

```markdown
# Test Plan: Pure-Activity (纯活动)

## Overview
- **项目名称**: Pure-Activity
- **框架类型**: 原生微信小程序
- **项目规模**: 大型 (95 Pages, 5 Components)
- **测试工具**: Minium + Python
- **测试重点**: 鉴于页面数量庞大，测试将聚焦于核心业务流程（活动发布、报名、支付）、用户体系及微信特有API的交互。

## Suite: 01_用户鉴权模块
### TC-AUTH-001: 微信授权登录
- **Steps**:
  1. 启动小程序，监听首页 `onLoad` 生命周期。
  2. 检查页面是否包含“授权登录”或“获取头像昵称”按钮（适配新版微信登录规范）。
  3. 若存在，模拟点击按钮触发 `open-type="chooseAvatar"` 或 `getUserProfile`。
  4. Minium 模拟授权弹窗点击“允许”。
- **Expect**: 
  - 成功获取用户头像和昵称。
  - 本地 Storage 存储用户 Token 或 Session。
  - 页面 UI 更新为已登录状态。

### TC-AUTH-002: 手机号授权绑定
- **Steps**:
  1. 进入“个人中心”或“我的”页面。
  2. 点击“绑定手机号”按钮（`open-type="getPhoneNumber"`）。
  3. Minium 模拟点击授权弹窗“允许”。
  4. 验证后端接口是否收到加密数据并解密成功。
- **Expect**: 
  - 页面显示已绑定的手机号（中间四位掩码）。
  - 数据库更新用户手机号字段。

## Suite: 02_活动核心流程
*注：由于页面众多，选取核心业务路径进行自动化回归。*

### TC-ACT-001: 活动列表加载与筛选
- **Steps**:
  1. 跳转至活动列表页。
  2. 验证页面首次加载时是否有 Loading 状态。
  3. 检查列表数据渲染，至少有一条活动卡片。
  4. 切换顶部 Tab（如：全部、进行中、已结束）。
  5. 执行下拉刷新操作。
- **Expect**: 
  - 列表数据展示正常，图片加载无占位符错误。
  - Tab 切换数据过滤正确。
  - 下拉刷新触发 `onPullDownRefresh` 且数据更新。

### TC-ACT-002: 活动详情查看
- **Steps**:
  1. 在列表页点击任意一张活动卡片。
  2. 跳转至详情页，检查路由参数传递。
  3. 检查富文本内容（活动介绍）是否渲染正常。
  4. 检查“报名按钮”状态（未开始/立即报名/已结束）。
- **Expect**: 
  - 页面标题与活动名称一致。
  - 关键信息（时间、地点、费用）展示清晰。
  - 底部按钮状态与当前时间逻辑匹配。

### TC-ACT-003: 活动报名表单提交
- **Steps**:
  1. 在活动详情页点击“立即报名”。
  2. 跳转至报名表单页。
  3. 自动填充已登录用户的信息（姓名、电话）。
  4. 修改必填项，模拟用户输入。
  5. 点击“提交报名”。
- **Expect**: 
  - 表单校验逻辑生效（手机号格式、必填项非空）。
  - 提交成功后弹出成功提示。
  - 自动跳转至“报名成功”页或返回详情页（按钮变为“已报名”）。

## Suite: 03_支付与订单模块
### TC-PAY-001: 微信支付流程
- **Steps**:
  1. 在确认订单页，选择支付方式。
  2. 点击“去支付”。
  3. Minium 拦截 `wx.requestPayment` 调用。
  4. 模拟支付成功回调（需配合后端 Mock 或沙箱环境）。
- **Expect**: 
  - 正确拉起微信支付密码输入界面（或模拟调用成功）。
  - 支付成功后，订单状态变更为“已支付”。
  - 页面跳转至支付成功结果页。

### TC-ORD-001: 订单列表状态流转
- **Steps**:
  1. 进入“我的订单”页面。
  2. 检查不同 Tab 下的订单数据（待支付、待参加、已完成）。
  3. 对“待支付”订单执行“取消订单”操作。
- **Expect**: 
  - 订单列表数据与数据库状态一致。
  - 取消订单后，该订单从“待支付”列表消失，或在“已取消”列表显示。

## Suite: 04_微信特色功能
### TC-WX-001: 用户位置授权
- **Steps**:
  1. 进入“附近活动”或“活动地图”页面。
  2. 触发 `wx.getLocation` 或 `wx.chooseLocation`。
  3. Minium 模拟授权“允许使用地理位置”。
- **Expect**: 
  - 地图组件正确显示当前位置。
  - 列表根据位置距离排序。

### TC-WX-002: 分享功能
- **Steps**:
  1. 进入活动详情页。
  2. 点击右上角菜单“转发”或页面内分享按钮。
  3. 触发 `onShareAppMessage` 生命周期。
- **Expect**: 
  - 分享卡片标题、图片与当前活动信息一致。
  - 分享路径参数正确，他人点击可直达该活动详情。

### TC-WX-003: 生成活动海报
- **Steps**:
  1. 点击“生成海报”按钮。
  2. 调用 Canvas 绘图接口。
  3. 调用 `wx.saveImageToPhotosAlbum` 保存图片。
- **Expect**: 
  - 海报绘制无报错，包含二维码和活动信息。
  - 相册授权弹窗出现，授权后提示保存成功。

## Suite: 05_个人中心
### TC-USER-001: 个人信息修改
- **Steps**:
  1. 进入个人中心，点击头像或“编辑资料”。
  2. 修改昵称。
  3. 点击保存。
- **Expect**: 
  - 修改成功，个人中心页显示新昵称。

### TC-USER-002: 活动管理（主办方视角）
- **Steps**:
  1. 切换身份为主办方（如有此功能）。
  2. 点击“发布活动”。
  3. 填写活动表单（标题、时间、地点、封面图上传）。
  4. 提交审核。
- **Expect**: 
  - 图片上传成功。
  - 活动创建成功，状态为“审核中”。
```
