# Test Plan: 宠物纪

## Overview
- **Project Name**: 宠物纪
- **Framework**: WeChat Native (原生框架)
- **Scale**: Large (245 pages, 3 components)
- **Path**: D:\ShiGoTo\宠物纪
- **Test Tool**: Minium (Python)

**Summary**:
该项目为一个大型原生微信小程序，页面数量高达245个，推测为集宠物社交、服务、电商、医疗记录于一体的综合平台。由于页面众多，测试策略应采用分层测试：优先覆盖核心业务流程（P0），再逐步覆盖辅助功能（P1/P2）。

原生框架项目使用 Minium 进行自动化测试具有天然优势，可以直接利用 Minium 的元素定位和原生 API 调用能力。

---

## Suite: 01_User_Module (用户模块)
**Scope**: 覆盖用户授权、登录、注册及个人中心基础功能。

### TC-USER-001: 微信授权登录
- **Steps**:
  1. 启动小程序，检测是否处于未登录状态。
  2. 若未登录，触发登录流程（如点击“我的”页面或登录按钮）。
  3. 捕获微信授权弹窗（`<button open-type="getUserInfo">` 或新版头像昵称填写能力）。
  4. 点击“允许”授权。
  5. 验证页面跳转及用户信息展示。
- **Expect**: 
  - 成功获取用户头像和昵称。
  - 页面状态由“未登录”变为“已登录”，显示正确用户信息。
  - 数据库/后台成功创建或更新用户会话。

### TC-USER-002: 手机号绑定
- **Steps**:
  1. 进入个人中心或设置页面。
  2. 点击“绑定手机号”按钮。
  3. 触发 `<button open-type="getPhoneNumber">`。
  4. 在模拟器或真机调试中模拟授权手机号。
  5. 验证后台解密手机号是否成功。
- **Expect**: 
  - 界面提示“绑定成功”。
  - 个人中心展示已脱敏的手机号（如 138****8888）。

---

## Suite: 02_Pet_Management (宠物档案模块)
**Scope**: 宠物信息的新增、编辑、展示，推测为应用核心功能。

### TC-PET-001: 新增宠物档案
- **Steps**:
  1. 进入“我的宠物”或“首页”添加入口。
  2. 点击“添加宠物”按钮。
  3. 填写宠物名称、选择类型（猫/狗等）、品种、生日、体重。
  4. 上传宠物头像（调用 `wx.chooseImage` 或模拟图片选择）。
  5. 点击保存按钮。
- **Expect**: 
  - 表单校验通过（必填项检查）。
  - 列表页即时刷新显示新增的宠物卡片。
  - 详情页数据与录入一致。

### TC-PET-002: 编辑宠物体重记录
- **Steps**:
  1. 选择一只已存在的宠物进入详情页。
  2. 点击“记录体重”或“编辑”。
  3. 输入新的体重数值。
  4. 保存并返回。
- **Expect**: 
  - 体重曲线图或历史记录中新增一条数据。
  - 当前体重数值更新。

---

## Suite: 03_Social_Module (社区/动态模块)
**Scope**: 用户发布动态、评论、点赞及分享功能。

### TC-SOC-001: 发布图文动态
- **Steps**:
  1. 进入社区页面，点击“发布”按钮。
  2. 输入文本内容（测试边界值：如空文本、超长文本）。
  3. 选择相册图片（模拟添加 1 张或 9 张图片）。
  4. 点击“发布”。
- **Expect**: 
  - 发布成功后自动跳转至动态详情页或列表页。
  - 图片加载正常，文本显示无误。

### TC-SOC-002: 分享动态给微信好友
- **Steps**:
  1. 任意打开一条动态详情。
  2. 点击右上角“...”或页面内的分享按钮。
  3. 触发 `onShareAppMessage` 生命周期。
  4. 选择好友或群聊进行分享。
- **Expect**: 
  - 分享卡片标题、图片与当前动态内容一致。
  - 好友点击卡片能正确进入该动态详情页（路径参数正确）。

## Suite: 04_ECommerce_Module (商城/服务模块)
**Scope**: 商品浏览、购物车、下单及支付流程。

### TC-SHOP-001: 商品搜索与浏览
- **Steps**:
  1. 进入商城首页。
  2. 点击搜索框，输入关键词（如“猫粮”）。
  3. 验证搜索结果列表。
  4. 点击商品进入详情页，验证价格、规格信息。
- **Expect**: 
  - 搜索结果与关键词相关。
  - 商品详情页加载无白屏，数据正确。

### TC-SHOP-002: 订单支付流程 (关键)
- **Steps**:
  1. 在商品详情页选择规格，点击“立即购买”。
  2. 进入确认订单页，确认地址（需先有收货地址）。
  3. 点击“提交订单”。
  4. 捕获支付 API 调用 (`wx.requestPayment`)。
  5. 在测试环境模拟支付成功回调。
- **Expect**: 
  - 正确拉起微信支付界面（测试环境可 Mock 支付成功）。
  - 支付成功后订单状态变更为“待发货”或“已完成”。
  - 用户收到服务通知或模板消息。

## Suite: 05_Location_Service (位置服务模块)
**Scope**: 宠物医院/店铺定位、地图导航。

### TC-LOC-001: 查找附近宠物医院
- **Steps**:
  1. 进入“服务”或“地图”模块。
  2. 触发位置授权 (`wx.getLocation`)。
  3. 允许授权，查看地图标记点。
  4. 点击任意标记点查看详情。
- **Expect**: 
  - 地图正确居中到当前用户位置。
  - 周边医院/店铺标记点正确显示。
  - 点击导航能唤起地图路线规划。

---

## Suite: 06_Performance_Stability (性能与稳定性)
**Scope**: 针对245个页面的大型应用进行基础保障。

### TC-PERF-001: 页面路径扫描
- **Steps**:
  1. 读取 `app.json` 中的 `pages` 数组。
  2. 编写脚本遍历所有页面路径。
  3. 依次调用 `mini.open_page()` 进行跳转。
- **Expect**: 
  - 所有页面均能成功打开，无 404 或 JS 错误导致白屏。
  - 页面加载时间在合理范围内（如首屏 < 2s）。

### TC-PERF-002: 内存泄漏检测
- **Steps**:
  1. 反复进出包含大量图片或列表的页面（如社区 Feed 流）。
  2. 监控开发者工具中的内存占用曲线。
- **Expect**: 
  - 内存占用在退出页面后应回落，不应持续线性增长。
