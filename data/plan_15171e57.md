由于项目页面数量庞大（295个），且为原生开发，以下测试计划将基于“宠物纪”这一名称推断的核心业务流程进行设计。重点覆盖用户授权、宠物管理、电商/服务交易及社交互动等典型模块。

```markdown
# Test Plan: 宠物纪

## Overview
- **项目名称**: 宠物纪
- **框架类型**: 原生微信小程序
- **项目规模**: 大型（295个页面，3个组件）
- **测试工具**: Minium (Python)
- **测试策略**: 鉴于页面数量众多，采用POM（Page Object Model）模式进行封装，优先覆盖核心业务路径（登录授权、宠物档案、交易流程、社交互动）。

## Suite: 01_用户授权与账户模块
### TC-AUTH-001: 微信授权登录流程
- **Steps**:
  1. 启动小程序，检测是否处于未登录状态。
  2. 触发登录按钮（如点击“我的”或特定功能触发授权弹窗）。
  3. 模拟用户点击授权按钮（`<button open-type="getUserInfo">`）。
  4. 调用 `mini.get_current_page()` 获取页面数据，验证用户信息是否加载。
- **Expect**: 成功获取用户昵称、头像，页面跳转至首页或个人中心，无报错。

### TC-AUTH-002: 手机号绑定验证
- **Steps**:
  1. 进入个人中心/设置页面。
  2. 点击“绑定手机号”。
  3. 监听 `getPhoneNumber` 回调。
  4. 验证手机号格式及绑定状态更新。
- **Expect**: 手机号成功绑定，界面显示脱敏后的手机号（如 138****1234）。

## Suite: 02_宠物档案管理模块
### TC-PET-001: 新增宠物档案
- **Steps**:
  1. 进入“我的宠物”或“添加宠物”页面。
  2. 输入宠物名称、选择类型（猫/狗等）、品种、年龄。
  3. 上传宠物头像（调用 `wx.chooseImage` 或模拟选择媒体）。
  4. 点击保存。
- **Expect**: 列表页刷新显示新增的宠物卡片，信息与输入一致，图片加载正常。

### TC-PET-002: 宠物档案编辑与删除
- **Steps**:
  1. 在宠物列表中选择一个已有宠物进入详情页。
  2. 修改体重或备注信息。
  3. 保存修改。
  4. 返回列表，验证数据更新。
  5. 执行删除操作，验证列表中该条目消失。
- **Expect**: 编辑后数据实时更新，删除操作有二次确认弹窗，删除后列表无该记录。

## Suite: 03_商城与服务交易模块
### TC-TRADE-001: 商品浏览与购物车
- **Steps**:
  1. 首页进入商城板块。
  2. 滑动列表，点击商品进入详情页。
  3. 选择规格（如重量、口味），点击“加入购物车”。
  4. 切换至购物车页面，验证商品数量及规格。
- **Expect**: 购物车图标角标数字更新，购物车内商品信息准确。

### TC-TRADE-002: 订单支付流程（微信支付Mock）
- **Steps**:
  1. 在购物车点击“结算”。
  2. 选择收货地址（调用 `wx.chooseAddress`）。
  3. 提交订单，监听支付回调。
  4. 由于测试环境，模拟支付成功/失败状态。
- **Expect**: 正确唤起支付接口（或Mock返回成功），订单状态变更为“待发货”或“支付成功”，并生成订单号。

## Suite: 04_社区与互动模块
### TC-SOCIAL-001: 发布动态（图文/视频）
- **Steps**:
  1. 点击“发布”按钮（通常为底部“+”号）。
  2. 输入文本内容。
  3. 选择相册图片或视频（Mock `wx.chooseMedia`）。
  4. 点击发布。
- **Expect**: 发布成功提示，动态流中即时出现新发布的内容，且排版正常。

### TC-SOCIAL-002: 分享功能测试
- **Steps**:
  1. 进入某篇宠物文章或商品详情页。
  2. 点击右上角“...”或页面内分享按钮。
  3. 验证 `onShareAppMessage` 配置。
- **Expect**: 分享卡片标题、图片与配置一致，能够成功转发给微信好友或群聊。

## Suite: 05_位置与地图服务
### TC-MAP-001: 附近宠物店/医院定位
- **Steps**:
  1. 进入“服务”或“地图”相关页面。
  2. 触发定位权限授权（`wx.getLocation`）。
  3. 检查地图组件是否加载当前坐标周边的标记点。
- **Expect**: 地图正确显示用户位置，周边POI点（宠物店、医院）标记准确，点击标记可查看详情。

## Suite: 06_异常与兼容性测试
### TC-EXCP-001: 网络异常处理
- **Steps**:
  1. 利用 Minium 或开发者工具模拟网络断开。
  2. 触发数据请求操作（如刷新首页、提交订单）。
- **Expect**: 页面不崩溃，显示友好的网络错误提示（如“网络开小差了”），并提供重试按钮。

### TC-EXCP-002: 基础库版本兼容
- **Steps**:
  1. 在 project.config.json 中调整最低基础库版本设置。
  2. 运行核心流程冒烟测试。
- **Expect**: 在支持的最低版本基础库下，核心功能无 JS 报错，UI 布局无严重错乱。
```
