# Test Plan: 宠物纪

## Overview
- **Project Name**: 宠物纪
- **Framework**: WeChat Native (原生)
- **Scale**: Large (280 Pages, 3 Components)
- **Test Tool**: Minium (Python)
- **Test Strategy**: Given the large number of pages (280), this test plan prioritizes core business flows, WeChat-specific integration points (Login, Payment, Share), and critical user paths. The 3 components likely handle UI elements (like navigation bars or loading spinners) and should be tested for reusability across different pages.

## Suite: User Authorization & Account Management
### TC-AUTH-001: WeChat User Login
- **Steps**:
  1. Launch the Mini Program.
  2. Check if the user is logged in.
  3. If not logged in, trigger the `wx.login` flow or click the "WeChat Login" button.
  4. Verify the retrieval of the `code` and subsequent `openid` registration.
- **Expect**: User successfully logs in, and the home page displays user-specific data (or avatar).

### TC-AUTH-002: User Profile Authorization (Avatar/Nickname)
- **Steps**:
  1. Navigate to the "My Profile" page.
  2. Click "Edit Profile".
  3. Use the `button open-type="chooseAvatar"` to select a WeChat avatar.
  4. Input a nickname and save.
- **Expect**: Profile updates successfully; new avatar and nickname are persisted and displayed on the UI.

## Suite: Core Business - Pet Management
### TC-PET-001: Add New Pet Profile
- **Steps**:
  1. Navigate to the "My Pets" module.
  2. Click the "Add Pet" button.
  3. Fill in required details (Name, Type: Dog/Cat, Breed, Birthday).
  4. Upload a photo using the WeChat image picker.
  5. Click "Save".
- **Expect**: New pet profile is created and appears in the pet list. Image uploaded successfully.

### TC-PET-002: Edit Pet Information
- **Steps**:
  1. Select an existing pet from the list.
  2. Click "Edit".
  3. Modify the weight or age.
  4. Save changes.
- **Expect**: Pet details are updated on the detail page and list view.

## Suite: E-Commerce & Payment (WeChat Pay)
### TC-PAY-001: Product Purchase & Payment Flow
- **Steps**:
  1. Navigate to the "Mall" or "Service" section.
  2. Select a product (e.g., Pet Food or Grooming Service).
  3. Add to cart or click "Buy Now".
  4. Confirm order details.
  5. Trigger `wx.requestPayment`.
  6. Complete payment in the WeChat sandbox/test environment.
- **Expect**: Payment interface is called successfully; order status changes to "Paid" upon success callback.

### TC-PAY-002: Order List & Status Verification
- **Steps**:
  1. Navigate to "My Orders".
  2. Check tabs for "Pending Payment", "Paid", "Completed".
  3. Verify the order created in TC-PAY-001 exists under the correct tab.
- **Expect**: Order list displays correct status and product summary.

## Suite: Social & Community Features
### TC-SOC-001: Publish Dynamic/Moment
- **Steps**:
  1. Navigate to the "Community" or "Square" page.
  2. Click the "+" or "Publish" button.
  3. Select images/videos from the album (`wx.chooseMedia`).
  4. Enter text content.
  5. Submit the post.
- **Expect**: Post is uploaded, appears in the community feed immediately.

### TC-SOC-002: Share Content to WeChat Chat
- **Steps**:
  1. Open a specific article or pet dynamic.
  2. Click the "Share" button (top right menu or on-page button).
  3. Select "Send to Friend".
  4. Verify the share card title and image.
- **Expect**: Share menu opens; content can be shared to a specific WeChat friend or group.

## Suite: Location Services (LBS)
### TC-LOC-001: Nearby Services (Pet Hospitals/Stores)
- **Steps**:
  1. Navigate to the "Nearby" or "Map" section.
  2. Trigger `wx.getLocation` to authorize location access.
  3. Verify the map centers on the user's current location.
  4. Check if nearby markers (Pet Hospitals, Grooming Shops) are displayed.
- **Expect**: Location permission prompt appears; map loads with accurate nearby points of interest.
