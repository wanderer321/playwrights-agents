以下是基于Minium框架制定的结构化测试计划：

```markdown
# Test Plan: 宠物纪

## Overview
- **项目名称**: 宠物纪
- **项目路径**: D:\ShiGoTo\宠物纪
- **技术栈**: 原生微信小程序框架
- **项目规模**: 大型 (279 Pages, 3 Components)
- **测试工具**: Minium (Python)
- **测试策略**: 鉴于页面数量巨大，优先覆盖核心业务流程（如：用户体系、商品/服务交易、订单管理）及微信特有API调用。采用POM（Page Object Model）模式封装页面元素，以提高代码复用率。

## Suite: 用户模块
*覆盖用户全生命周期管理，重点关注微信授权流程。*

### TC-USER-001: 微信授权登录
- **Steps**:
  1. 启动小程序，检测当前登录状态。
  2. 若未登录，触发登录流程（如点击“我的”页面）。
  3. 调用 `mini.get_wx_login_code()` 获取 code。
  4. 模拟点击授权按钮（open-type="getUserInfo" 或新版头像昵称填写）。
- **Expect**: 成功获取用户基本信息，跳转至首页或个人中心，UI 显示正确用户头像和昵称。

### TC-USER-002: 手机号授权绑定
- **Steps**:
  1. 进入个人中心或结算页，点击“绑定手机号”。
  2. 模拟点击微信官方手机号授权按钮。
  3. Minium 捕获 `getPhoneNumber` 回调。
- **Expect**: 成功获取加密手机号数据，解密后显示正确手机号，数据库更新用户绑定状态。

### TC-USER-003: 用户资料修改
- **Steps**:
  1. 进入“编辑资料”页面。
  2. 修改宠物昵称、品种、年龄等信息。
  3. 点击保存。
- **Expect**: 修改成功，页面刷新后显示最新数据，接口返回成功状态码。

## Suite: 首页与导航模块
*验证大型小程序的路由跳转及页面加载性能。*

### TC-HOME-001: TabBar 导航切换
- **Steps**:
  1. 启动小程序进入首页。
  2. 依次点击 TabBar 的各个选项（首页、分类、购物车、我的）。
  3. 验证页面加载时间。
- **Expect**: 页面切换流畅，无白屏，无 JS 报错，每个 TabBar 页面元素渲染正确。

### TC-HOME-002: 首页轮播图与活动入口
- **Steps**:
  1. 检查首页轮播图组件。
  2. 滑动轮播图，点击指定 banner。
  3. 验证跳转目标页面路径是否正确。
- **Expect**: 轮播图自动播放正常，点击跳转至对应活动页或商品详情页。

### TC-HOME-003: 全局搜索功能
- **Steps**:
  1. 点击首页搜索框。
  2. 输入关键词（如“猫粮”）。
  3. 点击搜索按钮。
- **Expect**: 跳转至搜索结果页，列表展示相关商品/服务，无结果时显示空状态提示。

## Suite: 商品交易与订单模块
*核心业务价值模块，涉及支付与数据一致性。*

### TC-TRADE-001: 商品详情浏览与规格选择
- **Steps**:
  1. 从列表页点击进入商品详情页。
  2. 滑动查看详情图。
  3. 点击“选择规格”弹窗，选择不同规格（如：重量、口味）。
  4. 验证价格变动。
- **Expect**: 详情页加载完整，规格切换时价格同步更新，库存显示正确。

### TC-TRADE-002: 加入购物车与数量调整
- **Steps**:
  1. 在详情页选择规格，点击“加入购物车”。
  2. 切换到购物车页面。
  3. 增加或减少商品数量。
  4. 验证全选功能及总价计算。
- **Expect**: 购物车图标角标数字更新正确，总价计算精确到小数点后两位，无数量溢出（超过库存）。

### TC-TRADE-003: 订单提交与微信支付
- **Steps**:
  1. 在购物车点击“结算”。
  2. 选择收货地址（若无则新增）。
  3. 点击“提交订单”。
  4. 调用 `mini.mock_wx_pay` 模拟微信支付成功回调。
- **Expect**: 订单生成，状态为“待发货/已支付”，跳转至支付成功页，微信支付接口调用参数正确。

### TC-TRADE-004: 订单取消与退款
- **Steps**:
  1. 进入“我的订单” -> “待付款”或“待发货”列表。
  2. 点击“取消订单”或“申请退款”。
  3. 填写退款原因并提交。
- **Expect**: 订单状态变更为“已取消”或“退款中”，库存回滚（若需验证需查库）。

## Suite: 宠物服务与位置模块
*针对“宠物纪”可能涉及的线下服务（如美容、医疗）。*

### TC-SERVICE-001: 定位服务授权
- **Steps**:
  1. 进入“附近门店”或“服务预约”页面。
  2. 触发 `wx.getLocation` 授权。
  3. 若用户拒绝授权，引导用户手动开启设置。
- **Expect**: 首次进入弹出授权弹窗，授权后显示当前位置，拒绝授权后显示引导提示而非崩溃。

### TC-SERVICE-002: 门店列表与导航
- **Steps**:
  1. 查看基于位置排序的门店列表。
  2. 点击“去这里”或“导航”按钮。
  3. 调用 `wx.openLocation` 打开地图。
- **Expect**: 列表按距离升序排列，地图显示正确的门店坐标。

## Suite: 互动与分享模块
*验证微信社交裂变能力。*

### TC-SHARE-001: 商品/文章转发分享
- **Steps**:
  1. 进入商品详情页或内容页。
  2. 点击右上角“...”菜单或页面内的“转发”按钮。
  3. 监听 `onShareAppMessage` 函数。
- **Expect**: 分享卡片标题、图片配置正确，转发参数（如邀请ID）携带正确。

### TC-SHARE-002: 生成分享海报
- **Steps**:
  1. 点击“生成海报”按钮。
  2. 验证 Canvas 绘图过程。
  3. 调用 `wx.saveImageToPhotosAlbum` 保存图片。
- **Expect**: 海报生成成功，包含当前页面二维码及用户信息，保存至相册成功。

## Suite: 异常与兼容性测试
*针对原生框架及大量页面的健壮性测试。*

### TC-EX-001: 网络异常处理
- **Steps**:
  1. 利用 Minium 模拟网络断开或弱网环境。
  2. 进行页面跳转或数据请求操作。
- **Expect**: 页面不崩溃，显示友好的网络错误提示，具备“重新加载”按钮。

### TC-EX-002: 权限拒绝处理
- **Steps**:
  1. 依次触发相机、相册、位置、录音等权限请求。
  2. 点击“拒绝”。
- **Expect**: 小程序不出现黑屏或卡死，给出相应的功能受限提示。
```
