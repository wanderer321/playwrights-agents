```markdown
# Test Plan: 宠物纪

## Overview
- **项目名称**: 宠物纪
- **框架类型**: 原生微信小程序
- **项目规模**: 大型 (268个页面, 3个组件)
- **测试工具**: Minium (Python)
- **测试重点**: 鉴于页面数量庞大，测试将优先覆盖核心业务路径（用户流程）、微信特有功能（支付、登录、分享）以及关键数据操作（宠物档案管理）。

## Suite: 用户鉴权与账户模块
*覆盖微信特有的登录流程与用户信息获取*

### TC-AUTH-001: 微信授权登录
- **Steps**:
  1. 启动小程序，检测本地是否存在登录态。
  2. 若未登录，点击“微信一键登录”按钮。
  3. 捕捉微信授权弹窗（若首次登录），点击“允许”。
  4. 验证页面跳转至首页或用户中心。
- **Expect**: 
  - 成功获取用户 OpenID 及 Session Key。
  - 界面显示用户微信头像和昵称。
  - `app.globalData` 中已存入用户信息。

### TC-AUTH-002: 获取手机号授权
- **Steps**:
  1. 进入“个人中心”或“绑定手机”页面。
  2. 点击“绑定手机号”按钮。
  3. 触发 `<button open-type="getPhoneNumber">` 能力。
  4. 点击弹窗中的“允许”。
- **Expect**: 
  - 后端成功解密手机号。
  - 页面显示已绑定的手机号（中间四位隐藏）。

## Suite: 宠物档案管理模块
*核心业务功能，涉及数据的增删改查 (CRUD)*

### TC-PET-001: 添加宠物档案
- **Steps**:
  1. 进入“我的宠物”页面。
  2. 点击“添加宠物”按钮。
  3. 输入宠物名称（如：旺财），选择类型（猫/狗）、品种、生日。
  4. 点击上传头像，调用 `wx.chooseImage` 选择相册图片。
  5. 点击“保存”。
- **Expect**: 
  - 宠物列表页刷新并显示新添加的宠物卡片。
  - 数据库成功写入记录。
  - 图片上传成功并正确展示。

### TC-PET-002: 编辑与删除宠物信息
- **Steps**:
  1. 在宠物列表中选择已存在的宠物卡片，点击进入详情。
  2. 点击“编辑”，修改体重字段。
  3. 保存并返回详情页，验证数据更新。
  4. 点击“删除宠物”，确认删除操作。
- **Expect**: 
  - 体重信息更新成功。
  - 删除后，列表中不再显示该宠物数据。

## Suite: 社区动态与互动模块
*涉及图片上传、内容发布、分享等交互*

### TC-COMM-001: 发布图文动态
- **Steps**:
  1. 点击底部导航栏“发布”按钮。
  2. 输入文本内容（如：今天遛狗啦）。
  3. 点击“添加图片”，选择 3 张图片。
  4. 点击“发布”按钮。
- **Expect**: 
  - 发布成功后自动跳转至动态详情页或社区流。
  - 图片加载正常，文字显示无误。

### TC-COMM-002: 动态分享功能
- **Steps**:
  1. 在动态详情页，点击右上角“...”或页面内的“分享”按钮。
  2. 触发 `onShareAppMessage` 生命周期。
  3. 选择转发给“文件传输助手”。
- **Expect**: 
  - 生成分享卡片，卡片标题和图片正确。
  - 点击分享卡片可重新进入该动态详情页。

## Suite: 商城与服务预约模块
*涉及微信支付、地理位置等敏感功能*

### TC-SHOP-001: 商品下单与支付流程
- **Steps**:
  1. 浏览商城列表，进入商品详情页。
  2. 选择规格（如：狗粮 5kg），点击“立即购买”。
  3. 确认订单信息，点击“提交订单”。
  4. 调用 `wx.requestPayment` 接口。
  5. **注意**: 测试环境通常使用沙箱支付或Mock，需确保支付回调逻辑正确。
- **Expect**: 
  - 正确拉起微信支付密码输入界面（或沙箱环境模拟）。
  - 支付成功后，订单状态变更为“待发货”或“已完成”。

### TC-SHOP-002: 门店导航 (地理位置)
- **Steps**:
  1. 进入“服务门店”或“宠物医院”页面。
  2. 点击“导航”按钮。
  3. 触发 `wx.openLocation` 或 `wx.chooseLocation`。
- **Expect**: 
  - 正确拉起地图组件，显示目标位置。
  - 可调用第三方地图App（腾讯/高德/百度）进行导航规划。

## Suite: 个人中心与设置
### TC-USER-001: 地址管理
- **Steps**:
  1. 进入个人中心 -> 收货地址。
  2. 点击“新增地址”。
  3. 使用“微信导入地址”功能或手动输入。
  4. 保存并设为默认。
- **Expect**: 
  - 地址列表显示新增条目。
  - 下单结算时，默认选中该地址。
```
