# Test Plan: zhihui-workshop

## Overview
**Project Name**: zhihui-workshop
**Framework**: React
**Test Tool**: Playwright

**Application Summary**:
Based on the project structure and directory naming conventions, `zhihui-workshop` appears to be a "Smart Workshop" or digital studio management platform. The application handles various media processing tasks, specifically focusing on ID photo generation, general photo management, poster creation, and order processing. The application likely serves users needing automated photo processing services or studio managers handling orders.

**Test Scope**:
The test plan covers the core business modules identified in the `tests` directory: Home, Hall, ID Photo, Photo, Poster, and Orders. The existing 168 test files suggest a mature testing base; this plan outlines the high-level structure for organizing these tests.

---

## Suite: Home Module (tests\home)
*Focus: Landing page, navigation, user authentication, and general application health.*

### TC-HOME-001: Verify Home Page Load
- **Steps**:
  1. Navigate to the application root URL.
  2. Wait for the page load state to be 'networkidle'.
- **Expect**: The home page renders successfully with the main header, footer, and navigation visible. No console errors are present.

### TC-HOME-002: Navigation Routing
- **Steps**:
  1. Locate the main navigation menu.
  2. Click on the 'Hall' (or equivalent primary) link.
  3. Verify URL change.
  4. Navigate back to Home.
- **Expect**: Routing functions correctly, directing the user to the intended module without page reload errors.

## Suite: ID Photo Module (tests\idphoto)
*Focus: Core functionality for ID photo creation, background removal, and cropping.*

### TC-IDP-001: Photo Upload Functionality
- **Steps**:
  1. Navigate to the ID Photo module.
  2. Click the upload button.
  3. Select a valid image file (JPG/PNG) from the fixture.
- **Expect**: Image uploads successfully and displays a preview in the editor.

### TC-IDP-002: Background Processing/Removal
- **Steps**:
  1. Upload a photo requiring background removal.
  2. Trigger the "Change Background" or "Auto Cutout" function.
  3. Select a standard background color (e.g., Blue, Red, White).
- **Expect**: The background is replaced with the selected color; edges are processed smoothly.

### TC-IDP-003: Photo Specifications Compliance
- **Steps**:
  1. Select a specific document type (e.g., "Passport", "Visa").
  2. Verify the crop area adjusts to the required dimensions.
  3. Confirm the output.
- **Expect**: The final image matches the aspect ratio and DPI requirements for the selected document type.
